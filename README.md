# Homebrew-Tap von COPAtec

```
brew install copa/tap/plausio
```

**[Plausio](https://plausio.app/)** analysiert öffentliche Kommentarbereiche auf Bot-Netze, Copy-&-Paste-Kampagnen und
Desinformation (Direktversion für den Mac). Dieses Repository enthält nur die Installationsbeschreibung (Cask); die
App liegt als Anhang der [Releases](https://github.com/copa/homebrew-tap/releases), ist von Apple notarisiert und
nicht quelloffen.

Plausio for Mac (direct edition) – analyses public comment sections for bot networks and disinformation.
This repository only contains the Homebrew cask; the notarized app is attached to the releases.
